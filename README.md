# Task 4: Information Architecture

## Project Overview
This task focuses on organizing the screens and content of a recreated Spotify mobile app into a clear and understandable structure.

## Objective
To understand how the app's screens are organized and how users can navigate between them.

## Process
- Reviewed the four recreated Spotify mobile app screens.
- Identified the visible screens and their relationships.
- Organized the screens into appropriate sections.
- Created an Information Architecture (IA) diagram to represent the app structure.

## Deliverable
An Information Architecture diagram representing the hierarchy and organization of the four recreated Spotify mobile app screens.

## Tool Used
- Google Stitch — AI-assisted Information Architecture diagram generation.
- GitHub — Project documentation and design showcase.
